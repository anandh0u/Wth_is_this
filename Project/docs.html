01 / Overview

The problem that does not exist

Normal productivity apps politely wait for you to use them. Lui does not. WTH Is This? watches its own boredom meter, judges tasks, walks across the Windows desktop, visits Chrome pages, plays local meme audio, and can prescribe Malayalam YouTube memes when it thinks you have fallen asleep.

02 / Features

What Lui currently does

01

Desktop pet

An always-on-top transparent pet walks across the primary Windows work area.

02

Todos

Add tasks, let Lui judge them, send them to the void, and restore them later.

03

Notes

Save and delete local notes in a dedicated panel Lui definitely does not read.

04

Calendar

Schedule events, record Lui’s verdict, void or restore them, and receive reminders.

05

Browser visits

The extension can inject Lui into the current safe webpage with a sarcastic line.

06

Controlled chaos

Open a meme, safely close a tab, undo the prank, or run a five-second demo.

07

Sleep memes

After Chrome reports sixty seconds of idle time, optional sleep mode opens an approved meme.

08

Local personality

Ollama can produce restricted verdicts; deterministic rules work without any model.

03 / Architecture

How the questionable pieces connect

Electron appUI, local state, reminders, boredom and menus
→
Local bridgeHTTP health + WebSocket on 127.0.0.1:17381
→
Chrome extensionActivity, idle state, safe tab actions and page pet
Pet windowTransparent, always on top, desktop movement
Lui engineRules or Ollama → sanitized JSON decision
Local storageTodos, notes, events and settings
Local audioRandom files from the bundled memes folder

The desktop app owns every action. The AI may suggest a verdict, but its response is normalized, restricted by context, and passed through the same safety gates as the deterministic fallback.

04 / Installation

Get Lui running

  1. Download and extract the full demo bundle.It contains the portable Windows app, Chrome extension, and setup guide.
  2. Run WTH-Is-This-0.1.2-portable.exe.Windows SmartScreen may warn because this hackathon build is not code-signed.
  3. Open chrome://extensions.Enable Developer mode, choose Load unpacked, and select the extracted chrome-extension folder.
  4. Open the Lui extension and press Connect desktop.Approve Chrome’s local-network prompt and keep the desktop app running.
  5. Confirm the app says connected.Use Visit page or Run 5-second demo for the fastest proof.

Run from source

git clone https://github.com/anandh0u/Wth_is_this.git
cd Wth_is_this
npm install
npm start

06 / Local AI

No training required

Lui works immediately with deterministic rules. For generated sarcastic verdicts, install Ollama and pull the configured lightweight model: 

ollama pull gemma3:270m
npm start

The default endpoint is http://127.0.0.1:11434. Override it with WTH_OLLAMA_URL and choose another model with WTH_OLLAMA_MODEL. Model output is limited to a verdict, a short line, and one allowed action.

noneopen_memeclose_activevoid_todopet_visit

07 / Safety

Chaos, with brakes

  • Automatic browser chaos and sleep pranks are disabled by default.
  • Pinned tabs, internal pages, account pages, localhost, and non-HTTP pages are protected.
  • Tabs containing passwords or edited form fields are not closed.
  • If safety cannot be proven, the extension refuses to close the tab.
  • The most recently prank-closed tab can be restored.
  • Voided todos and calendar events remain recoverable.
  • Sleep pranks have a ten-minute cooldown.
  • Unknown AI actions are replaced with none.
  • Todo decisions cannot trigger browser-tab closure.

08 / Data & privacy

Mostly stays on your machine

Todos, notes, calendar events, and settings are stored in Electron’s local user-data directory as wth-state.json. The desktop-extension bridge binds only to 127.0.0.1:17381. Ollama requests stay on 127.0.0.1 unless you deliberately override the endpoint.

The Chrome extension requests tabs, scripting, storage, idle, and website access so it can inspect the active tab’s safety state and display Lui. The demo has no remote account, analytics service, or cloud database. Meme links open YouTube and use YouTube’s services.

09 / Troubleshooting

When Lui refuses to cooperate

The extension says waiting or connection refused.

Start the desktop app first, press Connect desktop, and approve Chrome’s local-network permission. Only one app instance should be running.

Lui will not close a tab.

This is usually intentional. Pinned, internal, protected, localhost, password, and edited-form tabs are spared.

Automatic memes do not start.

Enable Pet, Allow browser chaos, and Allow sleep pranks. Chrome must report idle and the ten-minute cooldown must have elapsed.

Local AI is unavailable.

Run Ollama, pull gemma3:270m, and verify it responds on port 11434. Lui uses rules meanwhile.

Windows displays a security warning.

The portable demo is not code-signed. Verify it came from the official GitHub release before running it.
